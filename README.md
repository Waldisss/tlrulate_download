# Rulate → FB2

Пользовательский скрипт для Firefox и Tampermonkey. Он добавляет кнопку **«Скачать том в FB2»** возле названия каждого тома на странице оглавления книги Rulate. Кнопка собирает главы, которые доступны для чтения в текущем аккаунте, в один файл с обложкой и иллюстрациями. Название книги и автор берутся со страницы.

## Установка

1. Установите расширение [Tampermonkey для Firefox](https://addons.mozilla.org/firefox/addon/tampermonkey/).
2. Откройте файл [`rulate-fb2.user.js`](./rulate-fb2.user.js) на GitHub и нажмите **Raw / Скачать исходный файл**. Tampermonkey предложит установить скрипт.
3. Подтвердите разрешение на запросы к `tl.rulate.ru` и `i.imgur.com`. Они нужны для обложки и иллюстраций.
4. Откройте оглавление нужной книги на `tl.rulate.ru` в Firefox. Если главы куплены, войдите в свой аккаунт обычным способом.

Скрипт действует на страницах оглавления `/book/<id>`. Логин и пароль в скрипт вводить не нужно.

## Использование

1. Над оглавлением выберите **«Выводить главы по: Все»**.
2. Нажмите **«Скачать том в FB2»** рядом с нужным томом. Отмечать главы галочками не требуется.
3. Дождитесь завершения: возле кнопки появятся текущая глава и итоговое число сохранённых и пропущенных глав. Кнопка **«Отмена»** прекращает выгрузку без создания файла.
4. Если повторные сетевые попытки не помогли, выберите **«Повторить»**, **«Сохранить неполный»** или **«Отмена»**. При пропуске закрытых глав имя файла также содержит пометку «неполный».

Скрипт загружает главы последовательно с интервалом не менее секунды и допускает только одну выгрузку за раз. Держите вкладку открытой до появления файла. Прогресс хранится в памяти вкладки, поэтому после перезагрузки выгрузку нужно начать заново.

Иллюстрации загружаются с Rulate и `i.imgur.com`. Если отдельное изображение недоступно или имеет неподдерживаемый формат, книга сохраняется с отметкой об этом в итогах. Поддерживаются JPEG, PNG и GIF.

## Проверка и ограничения

Для разработки нужны Node.js и npm. Выполните `npm ci`, затем `npm test`. Тесты используют искусственные HTML-страницы и не содержат текст произведений. При наличии схемы FictionBook можно дополнительно проверить созданный XML командой `FB2_SCHEMA=/путь/к/FictionBook.xsd npm test` (рядом со схемой должны лежать импортируемые ей XSD-файлы).

Разбор проверен на HTML открытой главы, а созданный FB2 прошёл проверку по схеме FictionBook. Проверка купленных глав требует сессии владельца аккаунта. Скрипт распознаёт отказ в доступе и не помещает страницу отказа в книгу.

Версия 1.1 рассчитана на разметку оглавления и чтения Rulate с маршрутами `/book/<id>` и `/ready_new`. Если сайт изменит разметку или способ входа, выгрузка остановится с сообщением об ошибке. Публичный репозиторий содержит только код и искусственные тестовые данные; скачанные главы и данные сессии в него не добавляются.
